# Megabac Admin Tool

Outil d'administration pour gérer le contenu pédagogique de Megabac.

## Structure

```
outil-admin/
├── index.html          # Page HTML
├── style.css           # Styles
└── app.js              # Logique (CRUD, aperçus, File System Access API)
```

## Fonctionnalités

- [ ] Interface de gestion du contenu
- [ ] Import/export de données
- [ ] Gestion des versions
- [ ] Génération des fichiers JSON
- [ ] Validation des données

## Utilisation

```bash
# Ouvrir index.html dans un navigateur
open outil-admin/index.html
```
