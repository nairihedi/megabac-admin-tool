MegaBac — Administration des données

Cet outil édite directement les fichiers JSON du serveur de contenu (structure exemple-donnees-serveur/) sans passer par un backend : choisis le dossier racine pour commencer.

Fonctionne dans Edge ou Chrome, servi via une URL http:// ou https:// (pas en ouvrant le fichier directement) — voir le README-ADMIN.md à côté de ce fichier.
