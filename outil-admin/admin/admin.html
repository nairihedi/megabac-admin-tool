MegaBac — Administration des données

← Accueil

Mode local : cet outil édite directement les fichiers JSON d'un dossier de ton ordinateur (structure exemple-donnees-serveur/) sans passer par un backend : choisis le dossier racine pour commencer.

Fonctionne dans Edge ou Chrome, servi via une URL http:// ou https:// (pas en ouvrant le fichier directement) — voir le README-ADMIN.md à côté de ce fichier.

Mode distant : connecte-toi pour modifier les données hébergées sur le serveur ().
